- https://github.com/ARedomaDigital/skills-redoma — skills gerais.
- https://github.com/ARedomaDigital/skills-equipe — skills internas, com acesso privado.

Sou iniciante. Execute as etapas possíveis e explique de forma simples o que preciso fazer pessoalmente, como entrar na minha conta GitHub ou aceitar um convite. Nunca peça minha senha ou token no chat.

Verifique Git, Python 3.10+, Codex e, no Windows, tzdata. Confira os dois repositórios e minhas permissões de leitura e escrita. Clone-os em pastas irmãs, preservando arquivos existentes. Leia os READMEs e localize as skills redoma-welcoming e redoma-tutorial pelo catalog.json. Use essas skills para concluir a configuração.

Instale todas as skills próprias disponíveis dos DOIS catálogos em minha pasta pessoal .agents/skills, sem sobrescrever alterações locais. Instale também as skills externas pelas fontes oficiais previstas no repositório público. Para componentes de plugins ou do sistema, use o fornecedor correto e me informe o que faltar. Cada serviço conectado deve usar minha própria conta.

Configure a consulta às minhas duas raízes pessoais .codex/skills e .agents/skills. Adapte caminhos a este computador. Prepare a rotina de receber e enviar atualizações na primeira mensagem humana do dia, uma tentativa por data America/Sao_Paulo, e quando eu pedir explicitamente. Preserve instruções existentes. Sem agendamento por intervalo ou no login. Se o mecanismo de publicação ainda não atender esta máquina, informe o bloqueio exato em vez de instalar uma automação que apenas pareça funcionar.

Antes de enviar, atualize as cópias Git e compare edições locais com a versão anterior e com a recebida. Preserve conflitos para revisão. Envie conteúdo geral somente a skills-redoma e conteúdo interno somente a skills-equipe. Não copie skills externas para nossos repositórios. Não use force push. Não exclua uma skill compartilhada só porque ela não existe neste computador.

Termine verificando instalação e recebimento. Para um envio real autorizado, verifique o commit remoto. Mostre separadamente o que funcionou nos dois repositórios, o que falta e três frases curtas que eu possa usar para baixar, enviar e pedir ajuda. Não afirme que os outros computadores já foram configurados.
